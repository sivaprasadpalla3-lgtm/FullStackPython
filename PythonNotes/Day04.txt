# Day 4 — Set, Dictionary, Boolean, None & Type Casting

---

# 1. Set (`set`)

## What is a Set?

A set is a built-in Python data type used to store unique elements.

### Properties of Set

- Does not allow duplicate values
- Mutable — elements can be added or removed
- Unordered — items do not have a fixed position
- Represented using curly braces `{}` 
- Set elements must be immutable, such as `int`, `float`, `string`, and `tuple`

---

## Syntax

```python
set_name = {item1, item2, item3}
```

## Example

```python
student_ids = {101, 102, 103, 104}

print(student_ids)
```

### Possible Output

```text
{104, 101, 102, 103}
```

### Important Note

The order may change because sets are unordered.

---

# 2. Checking the Data Type of a Set

```python
student_ids = {101, 102, 103, 104}

print(type(student_ids))
```

### Output

```text
<class 'set'>
```

---

# 3. Duplicate Values are Automatically Removed

Sets do not allow duplicate values.

## Example

```python
student_ids = {101, 102, 103, 101}

print(student_ids)
```

### Output

```text
{101, 102, 103}
```

The duplicate value `101` is removed automatically.

# 4. Empty Set

Many beginners make this mistake.

## Incorrect

```python
s = {}

print(type(s))
```

### Output

```text
<class 'dict'>
```

`{}` creates an empty dictionary, not an empty set.

---

## Correct

```python
s = set()

print(s)
print(type(s))
```

### Output

```text
set()
<class 'set'>
```

# 24. Type Casting

## What is Type Casting?

Type casting is the process of converting one data type into another.

## Examples

```text
Integer → Float
String  → Integer
Float   → String
```

---

# 25. Types of Type Casting

There are two types:

```text
1. Implicit Type Casting
2. Explicit Type Casting
```

---

# 26. Implicit Type Casting

## Definition

Implicit type casting is automatic conversion performed by Python during an operation.

Python automatically converts a smaller compatible type into a larger compatible type during an operation.

---

## Example

```python
a = 10       # int
b = 12.5     # float

print(a + b)
```

### Output

```text
22.5
```

Python converts:

```text
10 → 10.0
```

before performing the addition.

Conceptually:

```text
10 + 12.5
 ↓
10.0 + 12.5
 ↓
22.5
```

---

# 27. Another Example of Implicit Conversion

```python
a = True
b = 5

print(a + b)
```

### Output

```text
6
```

Because:

```text
True  = 1
False = 0
```

Therefore:

```text
True + 5
1 + 5
6
```

---

# 28. Explicit Type Casting

## Definition

Explicit type casting is manual conversion performed by the programmer.

The programmer uses built-in functions to convert one data type into another.

---

# 41. Dictionary Conversion

A dictionary requires an iterable containing key-value pairs.

Each item must contain exactly two values:

```text
key
value
```

---

# 42. Correct Dictionary Conversion

```python
data = [
    ("name", "Raju"),
    ("age", 23)
]

student = dict(data)

print(student)
```

### Output

```text
{'name': 'Raju', 'age': 23}
```

---

# 43. Understanding Dictionary Conversion

The input:

```python
[
    ("name", "Raju"),
    ("age", 23)
]
```

contains pairs:

```text
("name", "Raju")
("age", 23)
```

The `dict()` function converts them into:

```text
"name" → "Raju"
"age"  → 23
```

Result:

```python
{
    "name": "Raju",
    "age": 23
}
```

---

# 44. Incorrect Dictionary Conversion

```python
dict([1, 2])
```

### Result

```text
TypeError
```

### Why?

Each element must contain exactly two values:

```text
(key, value)
```

But:

```text
1
2
```

are individual integers, not key-value pairs.

---

# 45. Important Conversion Error — Integer Is Not Iterable

This is invalid:

```python
list(10)
```

### Output

```text
TypeError: 'int' object is not iterable
```

Similarly:

```python
tuple(10)
set(10)
```

also produce a `TypeError`.

---

# 46. Why Does This Error Occur?

Functions such as:

```python
list()
tuple()
set()
```

expect an iterable.

Examples of iterable objects include:

```text
String
List
Tuple
Set
Range
```

An integer such as:

```text
10
```

is not iterable.

Therefore:

```python
list(10)
```

is invalid.

# 55. Key Interview Questions

## 1. What is a Set?

A set is an unordered collection of unique elements.

---

## 2. Does a Set allow duplicate values?

No.

```python
numbers = {10, 20, 20, 30}
```

becomes:

```text
{10, 20, 30}
```

---

## 3. How do you create an empty Set?

```python
s = set()
```

---

## 4. Why does `{}` create a dictionary instead of a Set?

Because `{}` is the literal syntax for an empty dictionary.

Use:

```python
set()
```

to create an empty set.

---

## 5. What is a Dictionary?

A dictionary stores data as key-value pairs.

Example:

```python
student = {
    "name": "Raju",
    "age": 21
}
```

---

## 6. Are Dictionary Keys unique?

Yes.

Dictionary keys must be unique.

---

## 7. Can Dictionary values be duplicated?

Yes.

---

## 8. What happens with `student["marks"]` if the key does not exist?

It raises:

```text
KeyError
```

---

## 9. What happens with `student.get("marks")` if the key does not exist?

It returns:

```text
None
```

without raising an error.

---

## 10. What is Boolean?

Boolean represents:

```text
True
False
```

---

## 11. What is `None`?

`None` represents the absence of a value or no value.

Its type is:

```text
NoneType
```

---

## 12. What is Type Casting?

Type casting is the process of converting one data type into another.

---

## 13. What is Implicit Type Casting?

It is automatic type conversion performed by Python.

Example:

```python
10 + 12.5
```

Python converts the integer appropriately during the operation and produces:

```text
22.5
```

---

## 14. What is Explicit Type Casting?

It is manual conversion performed by the programmer.

Examples:

```python
int()
float()
str()
bool()
list()
tuple()
set()
dict()
```

---

## 15. What is the difference between Implicit and Explicit Casting?

```text
Implicit
   ↓
Automatic
   ↓
Python performs conversion

Explicit
   ↓
Manual
   ↓
Programmer performs conversion
```

---

## 16. What happens when `int(10.5)` is used?

Output:

```text
10
```

`int()` truncates the decimal part; it does not round it.

---

## 17. Why does `list(10)` give TypeError?

Because `list()` expects an iterable, and an integer is not iterable.

---

## 18. Why does `dict([1, 2])` give TypeError?

Because dictionary conversion requires key-value pairs, with exactly two values in each item.

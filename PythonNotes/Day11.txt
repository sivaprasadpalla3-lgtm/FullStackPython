Python Conditional Statements and Loops
1. if Statement
The if statement is used to execute a block of code only when a condition is True.
Syntax
if condition:
statement
Example
n = 10

if n > 0:
print("Positive number")
Execution
Python checks:
n > 0
10 > 0
True
Because the condition is True, Python executes the print() statement.
Output:
Positive number

2. if-else Statement
When we have two possible choices, we can use if-else.
Syntax
if condition:
statement
else:
statement
Example
n = 10

if n > 0:
print("Positive")
else:
print("Not Positive")
Execution
10 > 0 → True
Therefore:
Positive
If n = -10:
-10 > 0 → False
So the else block executes.

3. if-elif-else Statement
When we need to check multiple conditions, we use elif.
elif means:
else if
Syntax
if condition1:
block1

elif condition2:
block2

elif condition3:
block3

else:
else_block
Important Rule
Python checks conditions from top to bottom.
As soon as one condition becomes True:
Its block is executed.
The remaining elif conditions are skipped.
Python moves to the statement after the complete if-elif-else structure.

7. Nested if
An if statement written inside another if statement is called a nested if.
Example
Suppose a person is eligible only when:
Age >= 18
AND
Weight >= 50
We can write:
age = int(input("Enter age: "))

if weight >= 50:

else:
print("Not eligible due to age")

print("End")

How Nested if Works
Suppose:
age = 20
weight = 60
Python first checks:
age >= 18

20 >= 18 → True
Therefore Python enters the outer if.
Now it checks:
weight >= 50

60 >= 50 → True
Therefore:
Eligible
Then:
End
Output
Eligible
End

Case 2: Correct Age but Low Weight
age = 20
weight = 40
Outer condition:
20 >= 18 → True
Inner condition:
40 >= 50 → False
Output:
Not eligible due to weight
End

Case 3: Age Below 18
age = 17
weight = 60
Outer condition:
17 >= 18 → False
Python does not enter the inner if.
Output:
Not eligible due to age

11. How for Loop Works Internally
This is very important for understanding Python.
Consider:
l = [1, 2, 3, 4]

for i in l:
print(i)
Conceptually, Python performs something similar to:
iterator = iter(l)

while True:
try:
i = next(iterator)
print(i)
except StopIteration:
break
Important roles
iter()
↓
creates iterator

next()
↓
gets next value from iterator

for loop
↓
automatically performs this process
So the programmer does not need to manually call iter() and next() when using a for loop.
Python's for machinery handles it internally.

28. Most Important Interview Questions
Q1. What is an if statement?
An if statement is used to execute a block of code when a specified condition is True.
Q2. What is elif?
elif means else if. It is used to check additional conditions when the previous condition is false.
Q3. What happens when an if condition is true?
Its corresponding block executes, and the remaining elif/else blocks in that chain are skipped.
Q4. What is nested if?
An if statement written inside another if statement is called a nested if.
Q5. What is a loop?
A loop is used to repeatedly execute a block of code.
Q6. What are the two main loops in Python?
1. for loop
2. while loop
Q7. What is range()?
range() creates a range object representing a sequence of numbers.
Q8. Is the stop value included in range()?
No. The stop value is excluded.
range(1, 5)
produces:
1 2 3 4
Q9. What does iter() do?
iter() obtains an iterator from an iterable.
Q10. What does next() do?
next() retrieves the next value from an iterator.
Q11. What happens when an iterator has no more values?
It raises:
StopIteration
Q12. Does the programmer manually call next() in a normal for loop?
No. The for loop internally obtains an iterator and repeatedly requests the next value until the iterator is exhausted.

range() creates a range object → for obtains an iterator from it → the for loop repeatedly gets values from that iterator → when there are no more values, iteration stops.

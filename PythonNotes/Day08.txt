# 1. Introduction to Lists

A list is an ordered, mutable collection used to store multiple values in a single variable.

Lists are created using:

```text
[] or list()
```

Examples:

```python
numbers = [10, 20, 30]
names = ["Ravi", "Teja", "Ankit"]
mixed = [10, "Python", 5.5, True]

print(numbers)
print(names)
print(mixed)
```

---

# 2. List Properties

A Python list has the following properties:

```text
1. Ordered
   Elements maintain insertion order.

2. Mutable
   Elements can be modified.

3. Indexed
   Elements can be accessed using index positions.

4. Iterable
   Lists can be iterated using loops.

5. Allows Duplicates
   Duplicate values are allowed.

6. Dynamic Size
   The size can grow or shrink.

7. Heterogeneous
   A list can store different datatypes.
```

Example:

```python
data = [10, "Python", 5.5, True, 10]

print(data)
```

The list can contain integers, strings, floats, booleans, and duplicate values.

# 7. List Indexing

Indexing accesses elements using their index positions.

Example:

```python
data = [10, 20, 30, 40]

print(data[0])
print(data[-1])
```

Output:

```text
10
40
```

Python uses zero-based indexing.

```text
10  20  30  40
0   1   2   3
-4  -3  -2  -1
```

---

# 8. List Slicing

Slicing extracts part of a list.

Syntax:

```python
list[start:end:step]
```

Example:

```python
data = [10, 20, 30, 40, 50]

print(data[1:4])
```

Output:

```text
[20, 30, 40]
```

The start index is included and the end index is excluded.


Important pattern:

```text
[::-1]
```

means traverse the list from the end to the beginning.

# 22. append() vs extend()

This is an important interview concept.

Using `append()`:

```python

print(lst)
```

Output:

```text

```

Using `extend()`:

```python

```

```text

```

Remember:

```text

        ↓
adds the list as ONE element

extend([3, 4])
        ↓
adds 3 and 4 as separate elements
```

# 40. Introduction to Tuples

A tuple is an ordered, immutable collection used to store multiple values in a single variable.

Tuples are created using:

```text
( ) or tuple()
```

Examples:

```python
numbers = (10, 20, 30)
names = ("Ravi", "Teja", "Ankit")

```

---

# 41. Tuple Properties

According to the source, tuples are:

```text
1. Ordered
   Elements maintain insertion order.

2. Immutable
   Elements cannot be added, removed, or modified directly.

3. Iterable
   Can iterate through elements using loops.

4. Allows Duplicates
   Duplicate values are allowed.

5. Heterogeneous
   Can store different datatypes.

6. Supports Nested Objects
   Can contain tuples, lists, sets, dictionaries, etc.

7. Mutable Objects Can Change
   If a tuple contains mutable objects such as lists, those objects can be modified.

8. Faster Than Lists
   The source states that tuples generally consume less memory and provide faster access than lists.
```

# 65. Immutability of Tuples

Tuple elements cannot be modified.

Example:

```python
data = (10, 20, 30)

data[0] = 100
```

This causes:

```text
TypeError
```

Important:

```text
Tuple → immutable
```

Therefore, direct modification is not allowed.

---

# 66. Mutable Objects Inside Tuples

Although tuples are immutable, mutable objects stored inside them can still be modified.

Example:

```python
data = (10, [20, 30], 40)

data[1].append(50)

print(data)
```

Output:

```text
(10, [20, 30, 50], 40)
```

Why is this allowed?

Because:

```text
The tuple itself is immutable.
The list inside the tuple is mutable.
```

Therefore:

```python
data[0] = 100
```

is not allowed.

But:

```python
data[1].append(50)
```

is allowed.

# 67. Why Use Tuples?

According to the source, tuples are useful when:

```text
1. Data should not be modified.

2. Better memory efficiency is desired.

3. Faster access than lists is desired.

4. A fixed collection of values is needed.

5. Working with coordinates.

6. Working with dimensions.

7. Working with database records.

8. Packing and unpacking are useful.
```

Examples:

```python
location = (17.3850, 78.4867)

dimensions = (10, 20, 5)
```

# 68. List vs Tuple

| Feature | List | Tuple |
| --- | --- | --- |
| Syntax | [ ] | ( ) |
| Example | [10, 20, 30] | (10, 20, 30) |
| Mutability | Mutable | Immutable |
| Add Elements | Allowed | Not Allowed |
| Remove Elements | Allowed | Not Allowed |
| Modify Elements | Allowed | Not Allowed |
| Ordered | Yes | Yes |
| Indexed | Yes | Yes |
| Iterable | Yes | Yes |
| Allows Duplicates | Yes | Yes |
| Heterogeneous Data | Yes | Yes |
| Nested Structures | Yes | Yes |
| Dynamic Size | Yes | No, fixed after creation |
| Memory Usage | More Memory | Less Memory |
| Performance | Slightly Slower | Faster |
| Built-in Methods | Many Methods | Only 2 Methods |
| Sorting | sort() available | No sort() method |
| Copying | copy() available | No copy() method |
| Suitable For | Frequently changing data | Fixed data that should not change |
| Hashable | No | Yes, if all elements are immutable |
| Dictionary Key | Cannot be used | Can be used if hashable |

# 76. Interview Questions — Lists

## 1. What is a list in Python?

A list is an ordered, mutable collection used to store multiple values in one variable.

## 2. How do you create a list?

Using square brackets:

```python
data = [10, 20, 30]
```

or the `list()` constructor.

## 3. Are lists mutable?

Yes. List elements can be modified.

## 4. Can a list contain different datatypes?

Yes.

Example:

```python
data = [10, "Python", 5.5, True]
```

## 5. Can lists contain duplicate values?

Yes.

## 6. What is list indexing?

Accessing an element using its index.

```python
data[0]
```

## 7. What is list slicing?

Extracting part of a list using:

```python
list[start:end:step]
```

## 8. What does append() do?

Adds one element at the end.

## 9. What does extend() do?

Adds multiple elements from an iterable.

## 10. What does insert() do?

Inserts an element at a specified position.

## 11. What does remove() do?

Removes the first occurrence of a specified value.

## 12. What does pop() do?

Removes an element using its index. With no index, it removes the last element.

## 13. What does clear() do?

Removes all elements from the list.

## 14. What is the difference between remove() and pop()?

```text
remove() → removes by value
pop()    → removes by index
```

## 15. What is the difference between append() and extend()?

```text
append() → adds one element
extend() → adds elements from an iterable
```

## 16. What is the difference between sort() and sorted()?

```text
sort()   → modifies the original list
sorted() → returns a sorted list
```

## 17. What is a nested list?

A list inside another list.

```python
data = [[1, 2], [3, 4]]
```

## 18. What does copy() do?

Creates a shallow copy of a list.

# 77. Interview Questions — Tuples

## 1. What is a tuple?

A tuple is an ordered, immutable collection used to store multiple values in a single variable.

## 2. How do you create a tuple?

Using parentheses:

```python
data = (10, 20, 30)
```

or the `tuple()` constructor.

## 3. Are tuples mutable?

No. Tuples are immutable.

## 4. How do you create an empty tuple?

```python
t = ()
```

## 5. How do you create a single-element tuple?

```python
t = (10,)
```

The comma is important.

## 6. Why is `(10)` not a tuple?

Because:

```python
(10)
```

is treated as an integer expression.

A single-element tuple requires:

```python
(10,)
```

## 7. How do tuples support indexing?

Like lists:

```python
data[0]
data[-1]
```

## 8. Can tuples be sliced?

Yes.

```python
data[1:4]
```

## 9. How many built-in tuple methods are covered?

Two:

```text
count()
index()
```

## 10. What is tuple packing?

Automatically storing multiple values in a tuple.

```python
data = 10, 20, 30
```

## 11. What is tuple unpacking?

Extracting tuple elements into variables.

```python
a, b, c = (10, 20, 30)
```

## 12. Can a tuple contain a list?

Yes.

## 13. Can a list inside a tuple be modified?

Yes, because the list itself is mutable.

Example:

```python
data = (10, [20, 30], 40)

data[1].append(50)

print(data)
```

## 14. Why use tuples?

The source lists fixed data, memory efficiency, faster access, coordinates, dimensions, database records, and packing/unpacking as use cases.

# Day 10 — Conditional Statements & Control Statements in Python

---

# 1. Control Statements

Control statements are used to control the flow of execution of a program.

Normally, Python executes statements one after another from top to bottom.

Control statements allow the program to:

- Make decisions
- Repeat tasks
- Alter the normal flow of execution
- Execute code based on specific conditions
- Decide when code should execute
- Decide how many times code should execute
- Decide whether execution should continue, stop, or skip

---

# 2. What Do Control Statements Help the Program Decide?

Control statements help the program decide:

```text
1. Which code should execute
2. When code should execute
3. How many times code should execute
4. Whether execution should continue, stop, or skip
```

---

# 3. Types of Control Statements

Python control statements are broadly classified into three categories:

```text
1. Conditional Statements
   → Execute code based on conditions

2. Looping Statements
   → Execute code repeatedly

3. Jump Statements
   → Alter the normal flow of loops
```

---

# 4. Why Control Statements Are Important

Control statements help programs:

```text
1. Make decisions

2. Repeat tasks efficiently

3. Avoid unnecessary code repetition

4. Handle different situations dynamically

5. Control program execution flow
```

Without control statements, programs would execute sequentially and could not respond intelligently to different inputs or situations.

---

# 5. Conditional Statements

## Definition

Conditional statements are decision-making statements that execute different blocks of code depending on whether a specified condition evaluates to `True` or `False`.

They allow programs to make decisions and perform different actions based on different situations.

---

# 6. Real-Time Examples of Conditional Statements

Conditional statements can be used for:

```text
1. Checking stock availability
2. Validating login credentials
3. Determining grades
4. Checking voting eligibility
```

---

# 7. Types of Conditional Statements

The source covers four types:

```text
1. if
2. if-else
3. if-elif-else
4. Nested if
```

Quick comparison:

```text
if
    → Executes code when a condition is True

if-else
    → Executes one block if True and another if False

if-elif-else
    → Checks multiple conditions

Nested if
    → Places one conditional statement inside another
```

---

# 8. if Statement

## Definition

The `if` statement is the simplest conditional statement.

It executes a block of code only when the specified condition evaluates to `True`.

If the condition is `False`, the block is skipped.

---

# 9. if Statement Syntax

```python
if condition:
    statements
```

Important:

```text
if
↓
condition
↓
:
↓
indented statements
```

Python uses indentation to identify the block of code belonging to the `if` statement.

---

# 10. if Statement Example — Product Stock Availability

```python
stock = 25

if stock > 0:
    print("Product is available in stock")
```

Here:

```text
stock = 25
stock > 0
    ↓
True
    ↓
The print statement executes
```

Output:

```text
Product is available in stock
```

---

# 11. How if Works

Consider:

```python
stock = 25

if stock > 0:
    print("Product is available in stock")
```

Execution flow:

```text
Start
  ↓
stock = 25
  ↓
Check stock > 0
  ↓
Is condition True?
  ↓
YES
  ↓
Execute print()
  ↓
End
```

If:

```python
stock = 0
```

then:

```python
stock > 0
```

is `False`, so the print statement is skipped.

---

# 12. if-else Statement

## Definition

The `if-else` statement provides two possible execution paths.

One block executes when the condition is `True`.

Another block executes when the condition is `False`.

---

# 13. if-else Syntax

```python
if condition:
    statements
else:
    statements
```

Concept:

```text
             condition
                 ↓
          ┌──────┴──────┐
          ↓             ↓
        True          False
          ↓             ↓
      if block      else block
```

---

# 16. if-elif-else Statement

## Definition

The `if-elif-else` statement is used when multiple conditions need to be checked.

Python evaluates conditions from top to bottom.

As soon as a condition becomes `True`, its corresponding block executes and the remaining conditions are skipped.

---

# 17. if-elif-else Syntax

```python
if condition1:
    statements

elif condition2:
    statements

elif condition3:
    statements

else:
    statements
```

Important:

```text
if
 ↓
Check condition 1
 ↓
False
 ↓
elif
 ↓
Check condition 2
 ↓
False
 ↓
elif
 ↓
Check condition 3
 ↓
False
 ↓
else
```

If any condition becomes `True`, its block executes and the remaining conditions are skipped.

---

# 19. How if-elif-else Works

Example:

```python
marks = 75

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 50:
    print("C")
else:
    print("Fail")
```

Python checks from top to bottom.

```text
marks >= 90
    ↓
False

marks >= 75
    ↓
True
    ↓
Print B
    ↓
Stop checking remaining conditions
```

Important:

```text
The first True condition is executed.
Remaining conditions are skipped.
```

---

# 20. Nested if Statement

## Definition

A Nested `if` is an `if` statement placed inside another `if` or `else` block.

The inner condition is evaluated only when the outer condition is satisfied.

Nested `if` statements are useful when multiple levels of validation are required.

---

# 21. Nested if Syntax

```python
if condition1:
    if condition2:
        statements
    else:
        statements
else:
    statements
```

Concept:

```text
Outer condition
      ↓
   True?
   /   \
 Yes    No
  ↓      ↓
Inner   Outer
check   else
  ↓
True / False
```

---

# 22. Nested if Example — Product Purchase Eligibility

Source example:

```python
stock = 10
premium_member = True

if stock > 0:
    print("Product is available")

    if premium_member:
        print("Priority delivery available")
    else:
        print("Standard delivery available")
else:
    print("Product is out of stock")
```

---


Then Python checks the inner condition:

```python

```

Since:

```python

```

the program executes:


Output:

```text
Product is available
Priority delivery available
```

# 26. if vs if-else

## if

Use `if` when you only need to execute something when a condition is `True`.

```python
age = 20

if age >= 18:
    print("Adult")
```

If the condition is false, nothing is executed.

---

## if-else

Use `if-else` when you have two possible outcomes.

```python
age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

---

# 27. if-else vs if-elif-else

```text
if-else
   ↓
Two possible paths

if-elif-else
   ↓
Multiple possible paths
```

Example:

```python
age = 25

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

Two outcomes.

Multiple conditions:

```python
marks = 85

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 50:
    print("C")
else:
    print("Fail")
```

Multiple outcomes.

---

# 28. if-elif-else vs Nested if

## if-elif-else

Used when checking multiple conditions at the same decision level.

```python
marks = 80

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 50:
    print("C")
else:
    print("Fail")
```

---

## Nested if

Used when one decision depends on another decision.

```python
stock = 10
premium_member = True

if stock > 0:
    print("Product is available")

    if premium_member:
        print("Priority delivery available")
    else:
        print("Standard delivery available")
else:
    print("Product is out of stock")
```

# 30. Important Python Syntax Rules

## Rule 1 — Use a colon

Conditional statements require `:`.

Correct:

```python
if age >= 18:
    print("Eligible")
```

Incorrect:

```python
if age >= 18
    print("Eligible")
```

---

## Rule 2 — Use indentation

Correct:

```python
if age >= 18:
    print("Eligible")
```

The `print()` statement is indented.

---

## Rule 3 — else does not have a condition

Correct:

```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

---

## Rule 4 — elif is used for another condition

Correct:

```python
if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
else:
    print("C")
```

`and` requires both conditions to be true.

```python

    print("Allowed")
```

Concept:

```text

               ↓
             True
```

# 39. or

`or` requires at least one condition to be true.

```python

    print("Contact information available")
```

Concept:

```text
True OR False
     ↓
   True
```

# 40. not

```text
True
```

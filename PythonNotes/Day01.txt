# Day 1 — Introduction to Programming & Python

# 1. What is Programming?

Programming is the process of writing instructions that tell a computer what to do.

A computer cannot understand human language directly. It only understands machine-level instructions.

Programming languages act as a bridge between humans and computers.

A set of instructions written to perform a specific task is called a **Program**.

---

## Real-Time Examples

Programming is used in many real-world applications:

- ATM Withdrawal
- Online Shopping
- Food Delivery Apps
- Instagram Feed Loading
- YouTube Video Recommendations
- Uber Ride Booking

All these applications work because programmers write instructions that computers can execute.

---

# 2. What is a Programming Language?

A **Programming Language** is a language used to communicate with computers and create software applications.

## Examples

- Python
- Java
- C
- C++
- JavaScript
- C#

- Rust

---

# 3. Types of Programming Paradigms

Programming languages generally follow different programming styles called **paradigms**.

The two most common paradigms are:

1. Procedural Programming
2. Object-Oriented Programming (OOP)

---

# 4. Procedural Programming Language

Procedural Programming focuses on **Functions and Procedures**.

The program is divided into small functions, and execution happens step-by-step.

## Main Focus

- Functions
- Logic
- Sequence of Steps

## Examples

- C
- Pascal
- BASIC

---

## Real-Time Example — Food Ordering Process

Consider a food ordering application.

The food ordering process can be divided into the following steps:

```text
Step 1 → Login
Step 2 → Select Restaurant
Step 3 → Select Food
Step 4 → Payment
Step 5 → Order Confirmation
```

Each step can be written as a separate function.

```python
login()
select_restaurant()
select_food()
payment()
confirm_order()
```

This is Procedural Programming because execution happens step by step.

---

# 5. Characteristics of Procedural Programming

The main characteristics of Procedural Programming are:

- Function Based
- Top to Bottom Execution
- Easier for Small Applications
- Less Code Reusability
- Data is less secure
- Difficult to manage large projects

---

# 6. Advantages of Procedural Programming

The advantages of Procedural Programming are:

- Easy to Learn
- Easy to Write
- Fast Execution
- Suitable for Small Programs

---

# 7. Disadvantages of Procedural Programming

The disadvantages of Procedural Programming are:

- Difficult for Large Projects
- Data Security Issues
- Less Reusability
- Hard to Maintain

---

# 8. Object-Oriented Programming (OOP)

Object-Oriented Programming organizes code using **Objects and Classes**.

Instead of focusing only on functions, OOP focuses on real-world entities.

## Examples

- Customer
- Product
- Employee
- Bank Account

Everything is represented as an **Object**.

---

## Product Properties

A product can have the following properties:

- Product Name
- Price
- Rating
- Stock

## Product Behaviors

A product can perform the following behaviors:

In OOP, the product can be represented as a **Product Object**.

# 28. Memory Allocation — Procedural vs OOP

Understanding memory allocation is important because it explains how data is stored and managed.

---

# 29. Procedural Programming Memory Allocation

In Procedural Programming:

- Memory mainly stores variables and functions.
- Functions are called one after another.
- Data is usually shared globally or passed between functions.
- Memory usage is relatively low.

---

## Example

```python
name = "Ravi"
price = 500

calculate_bill()
print_bill()
```

---

## Simplified Memory Representation

```text
Stack Memory

name
price

Function Memory

calculate_bill()
print_bill()
```

Since there are only variables and functions, memory consumption is less.

---

# 30. OOP Memory Allocation

In OOP:

- Objects are created in Heap Memory.
- Each object stores attributes.
- Each object also stores a methods reference.

---

## Example — Product Object

```text
Product Object

name = Laptop
price = 50000
rating = 4.5
```

---

## Heap Memory

```text
Heap Memory

Product Object
    |
    ├── name
    ├── price
    └── rating
```

---

## Stack Memory

The stack can contain the reference to the object.

```text
Stack Memory

product1 → Object Reference
```

Objects consume more memory because every object stores its own state (attributes).

---

# 31. Procedural vs OOP Memory Allocation

| Feature | Procedural | OOP |
|---|---|---|
| Memory Usage | Less | More |
| Stores | Variables + Functions | Objects + Attributes |
| Object Creation | Not Required | Required |
| Heap Usage | Minimal | Heavy |
| Reusability | Low | High |
| Security | Lower | Higher |
| Suitable For | Small Programs | Large Applications |

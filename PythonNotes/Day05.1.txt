# Day 5.1 — Python Operators

---

# 1. What are Operators?

An operator is a symbol or keyword that performs an operation on one or more operands (values or variables).

## Example

```python
a = 10
b = 20

print(a + b)
```

### Here:

```text
+       → Operator
10, 20  → Operands
```

### Output

```text
30
```

---

# 2. Types of Operators in Python

Python provides the following types of operators:

| Operator Type | Purpose |
| --- | --- |
| Arithmetic | Mathematical calculations |
| Assignment | Assigning or updating values |
| Comparison (Relational) | Comparing values |
| Logical | Combining conditions |
| Bitwise | Operations on binary numbers |
| Membership | Checking whether an item exists |
| Identity | Checking whether two variables refer to the same object |
| Conditional (Ternary) | Writing simple if-else expressions |

# 29. Bitwise AND (&)

Both bits must be `1`.

```python

b = 15

```

### Output

```text

```

### Binary

```text
  1010
  1111
  ----
  1010
```

Therefore:

```text
1010 = 10
```

```text

```

In Python:

```python
~x
```

is equivalent to:



becomes:


# 41. `==` vs `is`

Consider:

```python
a = [10]
b = [10]

print(a == b)
print(a is b)
```

### Output

```text
True
False
```

### Explanation

```text
== → compares values
is → compares object identity / memory reference
```

The two lists contain the same value, so:

```python
a == b
```

is `True`.

But they are different list objects, so:

```python
a is b
```

is `False`.

# 49. Operator Precedence

Operator precedence determines which operation is performed first when an expression contains multiple operators.

## Highest to Lowest

| Priority | Operators |
| --- | --- |
| 1 | `()` |
| 2 | `**` |
| 3 | `+x`, `-x`, `~x` |
| 4 | `*`, `/`, `//`, `%` |
| 5 | `+`, `-` |
| 6 | `<<`, `>>` |
| 7 | `&` |
| 8 | `^` |
| 9 | `|` |
| 10 | `==`, `!=`, `<`, `>`, `<=`, `>=`, `is`, `is not`, `in`, `not in` |
| 11 | `not` |
| 12 | `and` |
| 13 | `or` |
| 14 | `value_if_true if condition else value_if_false` |

---

# 50. Precedence Example

```python
result = 10 + 5 * 2

print(result)
```

Multiplication has higher precedence than addition.

So:

```text
5 * 2 = 10
10 + 10 = 20
```

### Output

```text
20
```

---

# 51. Using Parentheses

Parentheses have the highest precedence.

```python
result = (10 + 5) * 2

print(result)
```

First:

```text
10 + 5 = 15
```

Then:

```text
15 * 2 = 30
```

### Output

```text
30
```


# 64. Why is `is None` preferred over `== None`?

`None` is a singleton object in Python.

The recommended way to check for it is:

```python
if value is None:
    print("No value")
```

This follows the recommendation in the Python style guide (PEP 8).

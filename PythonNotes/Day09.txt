# Day 9 — Sets & Dictionaries in Python

---

# 1. Introduction to Sets

A set is an unordered, mutable collection used to store unique values.

Sets are created using the `set()` function.

Sets automatically remove duplicate values.

Examples:

```python
numbers = {10, 20, 30}
names = {"Ravi", "Teja", "Ankit"}
mixed = {10, "Python", 5.5, True}

print(numbers)
```

---

# 2. Set Properties

According to the Day 9 source, sets have these properties:

```text
1. Unordered
   Elements do not maintain insertion order.

2. Mutable
   Elements can be added and removed.

3. Unindexed
   Elements cannot be accessed using index positions.

4. Iterable
   Sets can be iterated using loops.

5. Unique Elements
   Duplicate values are automatically removed.

6. Heterogeneous
   Sets can store different datatypes.

7. Dynamic Size
   Elements can be added or removed anytime.

8. Supports Nested Immutable Objects
   Sets can contain tuples and frozensets.

9. Mutable Objects Not Allowed
   Lists, sets, and dictionaries cannot be stored directly.
```

# 5. Membership Operators

Membership operators check whether an element exists in a set.

Operators:

```text
in
not in
```

Example:

```python
data = {10, 20, 30}

print(20 in data)
print(100 not in data)
```

Output:

```text
True
True
```

---

# 6. Union

Union combines all unique elements from both sets.

Operator:

```text
|
```

Example:

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
```

Output:

```text
{1, 2, 3, 4, 5}
```

Concept:

```text
A UNION B
↓
All elements from A and B
↓
Duplicates removed
```

Method form:

```python
print(a.union(b))
```

---

# 7. Intersection

Intersection returns common elements between sets.

Operator:

```text
&
```

Example:

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a & b)
```

Output:

```text
{2, 3}
```

Method form:

```python
print(a.intersection(b))
```

---

# 8. Difference

Difference returns elements present in the first set but not in the second set.

Operator:

```text
-
```

Example:

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a - b)
```

Output:

```text
{1}
```

Important:

```text
a - b
```

means:

```text
Elements in a but not in b
```

Method form:

```python
print(a.difference(b))
```

---

# 9. Symmetric Difference

Symmetric difference returns elements present in either set but not in both.

Operator:

```text
^
```

Example:

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a ^ b)
```

Output:

```text
{1, 4}
```

The common elements `2` and `3` are removed.

Method form:

```python
print(a.symmetric_difference(b))
```

---

# 10. Subset

A subset checks whether all elements of one set exist in another set.

Operator:

```text
<=
```

Example:

```python
a = {1, 2}
b = {1, 2, 3, 4}

print(a <= b)
```

Output:

```text
True
```

Because every element of `a` exists in `b`.

Method form:

```python
print(a.issubset(b))
```

---

# 11. Superset

A superset checks whether one set contains all elements of another set.

Operator:

```text
>=
```

Example:

```python
a = {1, 2, 3, 4}
b = {1, 2}

print(a >= b)
```

Output:

```text
True
```

Because `a` contains every element of `b`.

Method form:

```python
print(a.issuperset(b))
```

# 46. Introduction to Dictionaries

A dictionary is a collection of key-value pairs used to store related data.

Dictionaries are created using:

```text
{ }
```

or:

```text
dict()
```

Example:

```python

    "id": 101,
    "name": "Ravi",
    "course": "Python"
}
```

---

# 47. Dictionary Properties

According to the source:

```text
1. Ordered
   Maintains insertion order (Python 3.7+).

2. Mutable
   Items can be added, removed, and modified.

3. Indexed by Keys
   Values are accessed using keys, not numeric indexes.

4. Iterable
   Can iterate through keys, values, and items.

5. Unique Keys
   Duplicate keys are not allowed.

6. Duplicate Values Allowed
   Multiple keys can have the same value.

7. Heterogeneous
   Can store different datatypes.

8. Dynamic Size
   Can grow or shrink during execution.

9. Nested Structures Supported
   Can contain lists, tuples, sets, dictionaries, etc.

10. Keys Must Be Hashable
    Keys must be immutable/hashable objects.
```

# 87. Set vs Dictionary — Important Difference

Both can use curly braces:

```text
Set:
{10, 20, 30}

Dictionary:
{"name": "Ravi"}
```

The difference is:

```text
Set
    ↓
Stores individual unique values

Dictionary
    ↓
Stores key-value pairs
```

Example:

```python
s = {10, 20, 30}

d = {
    "id": 101,
    "name": "Ravi"
}
```

SET
    ↓

Created with set() for an empty set

DICTIONARY
    ↓

# 89. Important Set Interview Questions

## 1. What is a set in Python?

A set is an unordered, mutable collection used to store unique values.

## 2. Why are sets used?

They are used for removing duplicates, set operations, unique items, membership checking, and comparing collections.

## 3. Does a set allow duplicates?

No. Duplicate values are automatically removed.

## 4. Can we access set elements using an index?

No. Sets are unindexed.

## 5. How do you create an empty set?

```python
s = set()
```

## 6. What is the difference between `{}` and `set()`?

According to the source's creation examples:

```text
{}     → empty dictionary
set()  → empty set
```

## 7. What is union?

It combines all unique elements from two sets.

```python
a | b
```

## 8. What is intersection?

It returns common elements.

```python
a & b
```

## 9. What is difference?

It returns elements in the first set but not the second.

```python
a - b
```

## 10. What is symmetric difference?

It returns elements present in either set but not both.

```python
a ^ b
```

## 11. What is a subset?

A set whose every element exists in another set.

## 12. What is a superset?

A set that contains every element of another set.

## 13. What is the difference between remove() and discard()?

```text
remove()  → error if absent
discard() → no error if absent
```

## 14. What does set pop() do?

The source describes it as removing a random element.

## 15. What is frozenset?

An immutable version of a set.

## 16. Can a set contain a list?

No. The source states mutable objects such as lists, sets, and dictionaries cannot be stored directly.

## 17. Can a set contain a tuple?

Yes, according to the source, tuples can be stored as nested immutable objects.

# 90. Important Dictionary Interview Questions

## 1. What is a dictionary?

A dictionary is a collection of key-value pairs used to store related data.

## 2. How do you create a dictionary?

Using:

```python
{}
```

or:

```python
dict()
```

## 3. Are dictionaries mutable?

Yes.

## 4. Are dictionary keys unique?

Yes. Duplicate keys are not allowed.

## 5. Can dictionary values be duplicated?

Yes. Multiple keys can have the same value.

## 6. How are dictionary values accessed?

Using keys.

```python
student["name"]
```

## 7. Are dictionaries ordered?

The source states dictionaries maintain insertion order in Python 3.7+.

## 8. Can dictionary keys be lists?

No. The source states keys must be immutable/hashable objects.

## 9. Can dictionary values be lists?

Yes.

Example:

```python
student = {
    "marks": [90, 85, 88]
}
```

## 10. What does get() do?

It returns the value for a key.

## 11. What does keys() do?

It returns all keys.

## 12. What does values() do?

It returns all values.

## 13. What does items() do?

It returns key-value pairs.

## 14. What does update() do?

It updates the dictionary.

## 15. What does setdefault() do?

It returns a value and creates the key if it is absent.

## 16. What does pop() do?

It removes a specified key.

## 17. What does popitem() do?

The source states it removes the last inserted item.

## 18. What does clear() do?

It removes all dictionary items.

## 19. What does copy() do?

It creates a shallow copy.

## 20. What does fromkeys() do?

It creates a dictionary from keys.

## 21. What does membership checking do in a dictionary?

According to the source, membership checks keys.

# 97. Complete Set Revision Program

```python
# Creating a set
data = {10, 20, 30, 20}

print(data)

# Membership
print(20 in data)
print(100 not in data)

# Set operations
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
print(a & b)
print(a - b)
print(a ^ b)

# Subset and superset
x = {1, 2}
y = {1, 2, 3, 4}

print(x <= y)
print(y >= x)

# Built-in functions
print(len(data))
print(max(data))
print(min(data))
print(sum(data))
print(sorted(data))

# Methods
data.add(40)
data.update([50, 60])

print(data)

data.remove(10)
data.discard(100)
data.pop()

print(data)
```

# 98. Complete Dictionary Revision Program

```python
# Creating dictionary
student = {
    "id": 101,
    "name": "Ravi",
    "course": "Python"
}

# Accessing values
print(student["name"])
print(student["course"])

# Updating
student["course"] = "Full Stack Python"

# Adding
student["age"] = 22

# Membership
print("name" in student)
print("salary" not in student)

# Access methods
print(student.get("name"))
print(student.keys())
print(student.values())
print(student.items())

# Updating methods
student.update({"city": "Hyd"})
student.setdefault("phone", "Not Provided")

# Removing
student.pop("age")

print(student)
```

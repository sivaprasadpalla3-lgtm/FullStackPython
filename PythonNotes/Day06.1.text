# 1. Python input()

Python's `input()` function is used to take input from the user during program execution.

By default, `input()` returns a string.

We often convert the input into:

```text
int
float
list
tuple
set
dict
```

as needed.

---

```text

City
```

Input:


# 8. Understanding List of Integers

Consider:

```python
marks = list(map(int, input().split()))
```

This happens in steps.

### Step 1 — input()

```python
input()
```

Suppose the user enters:

```text
89 76 94 82
```

`input()` returns:

```text
"89 76 94 82"
```

This is a string.

### Step 2 — split()

```python
input().split()
```

Result:

```python
['89', '76', '94', '82']
```

These are still strings.

### Step 3 — map(int, ...)

```python
map(int, input().split())
```

Each string is converted into an integer.

Conceptually:

```text
'89' → 89
'76' → 76
'94' → 94
'82' → 82
```

### Step 4 — list()

```python
list(map(int, input().split()))
```

Final result:

```python
[89, 76, 94, 82]
```

# 13. Set Input

## Use Case

Set input can be used for selected image IDs where duplicates must be removed.

Example use case:

```text
Photo-sharing application
```

## Syntax

```python
selected_ids = set(map(int, input("Enter selected image IDs: ").split()))
print(selected_ids)
```

## Example

Input:

```text
Enter selected image IDs: 101 102 103 101 104
```

Output:

```text
{101, 102, 103, 104}
```

## Important

The duplicate value:

```text
101
```

appears more than once in the input, but the set keeps only one occurrence.

---

# 14. Understanding Set Input

The pattern is:

```python
set(map(int, input().split()))
```

Steps:

```text
input()
   ↓
split()
   ↓
map(int, ...)
   ↓
set()
```

Example:

```text
101 102 103 101 104
```

becomes:

```python
{101, 102, 103, 104}
```

The duplicate is removed.

# 16. Important Note About eval()

Only use `eval()` when the input is trusted.

```text
eval() can execute Python expressions supplied as input.
```

Therefore:

```text
Do NOT use eval() with untrusted user input.
```

The source specifically notes:

```text
Only use eval() when input is trusted.
```

Multiple inputs can be taken from one line and assigned to multiple variables.


## Syntax

```python

```

## Example

Input:

```text
Enter username and password: user01 mypassword123
```

Output:

```text
Username: user01
Password: mypassword123
```

---

# 18. Understanding Unpacking

Consider:

```python
username, password = input().split()
```

If the user enters:

```text
user01 mypassword123
```

then:

```python
input().split()
```

produces:

```python
['user01', 'mypassword123']
```

Python assigns the values:

```text
username → user01
password → mypassword123
```

This is called unpacking.

## 10. What does split() do?

`split()` separates a string into multiple parts.

Example:

```python
input().split()
```

Input:

```text
10 20 30
```

Result:

```python
['10', '20', '30']
```

---

## 11. Why do we use map(int, input().split())?

Because:

```python
input().split()
```

produces strings.

`map(int, ...)` converts each string into an integer.

Example:

```python
list(map(int, input().split()))
```

converts:

```text
10 20 30
```

into:

```python
[10, 20, 30]
```

---

## 12. Why do we use list() with map()?

`map()` produces an iterable of converted values.

Using:

```python
list(map(int, input().split()))
```

creates a list containing those converted values.

---

## 13. How do you take dictionary input according to these notes?

```python
profile = eval(input())
```

But `eval()` should only be used when the input is trusted.

---

## 14. What is unpacking?

Unpacking means assigning multiple values from an iterable to multiple variables.

Example:

```python
a, b = input().split()
```

Input:

```text
hello world
```

Then:

```text
a → hello
b → world
```

# Day 4.2 — Python Type Conversion (Type Casting)

---

# 1. What is Type Conversion?

Type conversion in Python refers to converting the value of one data type to another using built-in functions.

Common conversion functions are:

```python
int()
float()
str()
bool()
list()
tuple()
set()
dict()
```

Each conversion depends on the source type and the target type.

Some conversions are valid, while others produce an error.

---

# 2. Converting from `int`

## Given

```python
int_a = 2
```

## Conversion Table

| Target Type | Code | Output | Notes |
| --- | --- | --- | --- |
| `float` | `float(int_a)` | `2.0` | Valid |
| `str` | `str(int_a)` | `'2'` | Valid |
| `bool` | `bool(int_a)` | `True` | Non-zero ints are `True` |
| `list` | `list(int_a)` | Error | `int` is not iterable |
| `set` | `set(int_a)` | Error | `int` is not iterable |
| `tuple` | `tuple(int_a)` | Error | `int` is not iterable |
| `dict` | `dict(int_a)` | Error | `int` is not iterable |

# 58. Dictionary Conversion

To convert a list to a dictionary, it must be a list of key-value tuples.

## Example

```python
d = [
    ('name', 'teja'),
    ('batch', '22'),
    ('subject', 'python')
]

print(dict(d))
```

### Output

```text
{'name': 'teja', 'batch': '22', 'subject': 'python'}
```

---

# 59. Understanding Dictionary Conversion

The following list:

```python
d = [
    ('name', 'teja'),
    ('batch', '22'),
    ('subject', 'python')
]
```

contains three key-value pairs:

```text
name    → teja
batch   → 22
subject → python
```

Using:

```python
dict(d)
```

produces:

```python
{
    'name': 'teja',
    'batch': '22',
    'subject': 'python'
}
```

---

# 60. Important Iterable Concept

Functions such as:

```python
list()
tuple()
set()
dict()
```

can consume iterable objects when the supplied data has the required structure.

Examples of iterable types shown in these conversions:

```text
str
list
tuple
set
dict
```

An `int`, `float`, and `bool` are not iterable.

Therefore:

```python
list(2)
```

gives an error.

```python
list(3.1)
```

gives an error.

```python
list(False)
```

gives an error.

# 69. Important Points to Remember

```text
1. Type conversion means converting a value from one data type
   to another.

2. Common functions are int(), float(), str(), bool(),
   list(), tuple(), set(), and dict().

3. int(2) → float gives 2.0.

4. int(2) → str gives '2'.

5. A non-zero integer converts to True.

6. int is not iterable, so list(int), set(int),
   tuple(int), and dict(int) produce errors.

7. float can be converted to int, but the decimal part
   is truncated.

8. A non-zero float converts to True.

9. float is not iterable.

10. Numeric strings can be converted to numeric types.

11. int('10') is valid.

12. int('10.9') is not valid directly.

13. int('power') is invalid.

14. float('10.8') is valid.

15. float('power') is invalid.

16. A non-empty string converts to True.

17. list(string) creates a list of characters.

18. tuple(string) creates a tuple of characters.

19. set(string) creates a set of characters and removes
    duplicate characters.

20. dict(string) needs a proper key-value structure.

21. A list can be converted to str, bool, tuple, and set.

22. A list cannot directly become int or float.

23. A list can become a dictionary only when its elements
    are key-value pairs.

24. A tuple can be converted to str, bool, list, and set.

25. A tuple cannot directly become int or float.

26. A tuple can become a dictionary only when it contains
    key-value pairs.

27. A set can be converted to str, bool, list, and tuple.

28. When converting a set to a list or tuple, the order may vary.

29. A set cannot directly become int or float.

30. A dictionary converted to list, tuple, or set gives
    its keys.

31. A non-empty dictionary converts to True.

32. bool(False) is False.

33. int(False) is 0.

34. int(True) is 1.

35. float(False) is 0.0.

36. float(True) is 1.0.

37. bool values are not iterable.

38. Dictionary conversion requires key-value pairs.

39. A list of tuples can be converted into a dictionary.

    whether the target type requires a specific structure.
```

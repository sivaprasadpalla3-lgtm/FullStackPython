# 1. Understanding the print() Function in Python

Before learning output formatting, it is important to understand the basics of the `print()` function.

The `print()` function is used to display information on the screen.

---

# 2. What is print()?

The `print()` function in Python outputs:

```text
Text
Numbers
Variables
Any other data type
```

to the console.

It is one of the first functions every Python programmer learns.

---

# 3. Basic Syntax

```python
print(object, ..., sep=' ', end='\n', file=sys.stdout, flush=False)
```

## Parameters

### object

The data you want to display.

It can be:

```text
Text
Numbers
Variables
Other data
```

---

### sep

`sep` defines the separator between multiple items.

Default:

```text
' '
```

That means Python normally places a space between multiple items.

Example:

```python
print("Hello", "World")
```

Output:

```text
Hello World
```

---

### end

`end` specifies what Python prints at the end of the output.

Default:

```text
'\n'
```

`'\n'` means a new line.

---

### file

`file` specifies where the output is sent.

By default, the output goes to the console.

---

### flush

`flush` forces the output to be written immediately.

---

# 4. Basic Examples of print()

## A. Printing Text

```python
print("Hello, World!")
```

### Output

```text
Hello, World!
```

---

# 5. Printing Multiple Items

```python
name = "Alice"
age = 25

print("Name:", name, "Age:", age)
```

### Output

```text
Name: Alice Age: 25
```

Python automatically adds spaces between the items.

---

# 6. Using sep to Change the Separator

The `sep` parameter can be used to change the separator between multiple items.

```python
print("2024", "02", "07", sep="-")
```

### Output

```text
2024-02-07
```

Instead of spaces, hyphens are used as separators.

---

# 7. Using end to Control Line Endings

The `end` parameter controls what is printed at the end of the output.

Example:

```python
print("Hello,", end=" ")
print("World!")
```

### Output

```text
Hello, World!
```

Here:

```python
end=" "
```

prevents the default new line.

The second `print()` continues on the same line.

---

# 8. Printing Special Characters

Python output can contain special characters such as:

```text
\n
\t
```

---

# 9. New Line (\n)

`\n` is used to create a new line.

Example:

```python
print("Line 1\nLine 2")
```

### Output

```text
Line 1
Line 2
```

---

# 10. Tab (\t)

`\t` is used to insert a tab space.

Example:

```python
print("Name:\tAlice")
```

### Output

```text
Name:    Alice
```

---

# 11. Output Formatting

There are several ways to format output in Python.

The methods covered in this note are:

```text
1. Using Commas
2. Using Modulo Operator (%) Formatting
3. Using f-strings
4. Using str.format()
```

---

# 12. Method 1 — Using Commas

Using commas is the most basic way to print multiple items.

When multiple items are separated by commas inside `print()`, Python automatically adds a space between them.

Example:

```python
name = "Alice"
age = 25
score = 95.5

print("Name:", name, "Age:", age, "Score:", score)
```

### Output

```text
Name: Alice Age: 25 Score: 95.5
```

---

## Pros

```text
Simple
Easy for beginners
```

## Cons

```text
Limited control over formatting
Limited control over decimal places
Limited control over alignment
```

---

# 13. Method 2 — Using Modulo Operator (%) Formatting

Modulo formatting is an older method of formatting output.

It is similar to C-style formatting.

You use `%` with format specifiers such as:

```text
%s → String
%d → Integer
%f → Float
```

Example:

```python
name = "Bob"
age = 30
score = 88.75

print("Name: %s | Age: %d | Score: %.2f" % (name, age, score))
```

### Format Specifiers

```text
%s
```

String

```text
%d
```

Integer

```text
%.2f
```

Float with 2 decimal places

### Output

```text
Name: Bob | Age: 30 | Score: 88.75
```

---

## Pros

```text
Good control over formatting
```

## Cons

```text
Outdated
Not recommended for new projects
```

---

# 14. Method 3 — Using f-strings

f-strings are formatted string literals.

They were introduced in:

```text
Python 3.6+
```

This is the most modern and recommended method covered in the source.

Add an `f` before the string and use curly braces `{}` to insert variables directly.

Example:

```python
name = "Charlie"
age = 28
score = 92.389

print(f"Name: {name} | Age: {age} | Score: {score:.2f}")
```

### Explanation

```text
{name}
```

inserts the value of `name`.

```text
{age}
```

inserts the value of `age`.

```text
{score:.2f}
```

displays the score with 2 decimal places.

### Output

```text
Name: Charlie | Age: 28 | Score: 92.39
```

---

## Pros

```text
Clean
Concise
Easy to read
```

## Cons

```text
Only works in Python 3.6 and above
```

---

# 15. Method 4 — Using str.format()

The `str.format()` method uses `{}` as placeholders and `.format()` to insert variables.

The source notes that this method works in Python 2 and Python 3.

Example:

```python
name = "Diana"
age = 22
score = 89.456

print("Name: {} | Age: {} | Score: {:.1f}".format(name, age, score))
```

### Explanation

```text
{}
```

is a placeholder for variables.

```text
{:.1f}
```

formats the score with 1 decimal place.

### Output

```text
Name: Diana | Age: 22 | Score: 89.5
```

---

## Pros

```text
Flexible
Supports complex formatting
```

## Cons

```text
Slightly more verbose compared to f-strings
```

# 23. Important Differences

## Commas vs f-strings

### Commas

```python
print("Name:", name, "Age:", age)
```

Python automatically adds spaces between the items.

### f-string

```python
print(f"Name: {name} | Age: {age}")
```

The values are inserted directly inside the formatted string.

---

# 24. Modulo Formatting vs f-strings

### Modulo

```python
print("Score: %.2f" % score)
```

### f-string

```python
print(f"Score: {score:.2f}")
```

The source describes modulo formatting as an older method and f-strings as the modern recommended method.

---

# 25. f-strings vs str.format()

### f-string

```python
print(f"Name: {name} | Age: {age} | Score: {score:.2f}")
```

### str.format()

```python
print("Name: {} | Age: {} | Score: {:.2f}".format(name, age, score))
```

The source describes f-strings as clean, concise, and easy to read, while `str.format()` is flexible but slightly more verbose.

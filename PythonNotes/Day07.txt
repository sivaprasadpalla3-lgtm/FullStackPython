# Day 7 — Strings in Python

---

# 1. Introduction to Strings

A string is a sequence of characters enclosed within:

```text
Single quotes: ' '
Double quotes: " "
Triple single quotes: three single quotes
Triple double quotes: three double quotes
```

Strings are immutable, meaning once created, they cannot be changed directly.

---

# 2. Defining Strings

```python
# Defining strings
str1 = 'Hello'
str2 = "World"
str3 = '''This is a multi-line
string example.'''

print(str1)
print(str2)
print(str3)
```

Output:

```text
Hello
World
This is a multi-line
string example.
```

---

# 3. Operations on Strings

```text
1. Concatenation (+) - Joining two or more strings.
2. Repetition (*) - Repeating a string multiple times.
3. Indexing - Accessing individual characters using indices.
4. Slicing - Extracting a part (substring) of the string.
5. Membership (in, not in) - Checking if a substring exists within a string.
```

---

# 4. Concatenation (+)

Concatenation means joining two or more strings.

```python
str1 = "Hello"
str2 = "World"

result = str1 + " " + str2

print(result)
```

Output:

```text
Hello World
```

---

# 5. Repetition (*)

The `*` operator repeats a string multiple times.

```python
print("Python! " * 3)
```

Output:

```text
Python! Python! Python!
```

---

# 6. Indexing

Indexing accesses individual characters using their indexes.

Python uses zero-based indexing.

```python
text = "Python"

print(text[0])
```

Output:

```text
P
```

---

# 7. Negative Indexing

Negative indexing accesses characters from the end.

```python
text = "Python"

print(text[-1])
```

Output:

```text
n
```

For:

```python
text = "Python"
```

the indexes are:

```text
 P  y  t  h  o  n
 0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

---

# 8. Slicing

Slicing extracts a part (substring) of a string.

Syntax:

```python
string[start:end]
```

The start index is included and the end index is excluded.

```python
text = "Python"

print(text[0:3])
```

Output:

```text
Pyt
```

---

# 9. Slicing with Default Start

If start is omitted, Python uses 0.

```python
text = "Python"

print(text[:4])
```

Output:

```text
Pyth
```

---

# 10. Slicing with Default End

If end is omitted, Python continues to the end.

```python
text = "Python"

print(text[2:])
```

Output:

```text
thon
```

---

# 11. Membership

Membership operators:

```text
in
not in
```

They check whether a substring exists inside a string.

```python
text = "Python"

print("Pyt" in text)
print("Java" not in text)
```

Output:

```text
True
True
```

# 48. isdecimal() vs isdigit() vs isnumeric()

| String | isdecimal() | isdigit() | isnumeric() | Description |
| --- | --- | --- | --- | --- |
| '123' | True | True | True | ASCII decimal digits |
| '٣' | True | True | True | Arabic-Indic digit |
| '²' | False | True | True | Superscript 2 |
| '⅓' | False | False | True | Fraction one-third |
| '五' | False | False | True | Chinese numeral for five |
| 'Ⅷ' | False | False | True | Roman numeral 8 |
| 'abc' | False | False | False | Alphabetic characters |
| '12.3' | False | False | False | Contains a dot |
| '1a3' | False | False | False | Contains non-numeric character |

Quick relationship:

```text
isdecimal() → strictest
isdigit()   → broader
isnumeric() → most flexible
```

```text

rfind()  → last occurrence, -1 if absent
index()  → first occurrence, error if absent
rindex() → last occurrence, error if absent
```

# 75. Interview Questions

## 1. What is a string in Python?

A string is a sequence of characters enclosed in single quotes, double quotes, or triple quotes.

## 2. Are strings mutable or immutable?

Strings are immutable.

## 3. How can you create a multi-line string?

Using triple single quotes or triple double quotes.

## 4. What is concatenation?

Joining strings using `+`.

## 5. What is string repetition?

Repeating a string using `*`.

## 6. What is indexing?

Accessing an individual character using its index.

## 7. What is negative indexing?

Accessing characters from the end using negative indexes.

## 8. What is slicing?

Extracting a portion of a string.

## 9. What is the difference between find() and index()?

```text
find()  → returns -1 if not found
index() → raises an error if not found
```

## 10. What is the difference between rfind() and rindex()?

```text
rfind()  → last occurrence; -1 if absent
rindex() → last occurrence; error if absent
```

## 11. What does split() do?

It splits a string into a list.

## 12. What does join() do?

It joins iterable elements using a separator.

## 13. What does strip() do?

It removes leading and trailing characters; by default, spaces.

## 14. What is the difference between strip(), lstrip(), and rstrip()?

```text
strip()  → leading + trailing
lstrip() → leading
rstrip() → trailing
```

## 15. What is the difference between isdecimal(), isdigit(), and isnumeric()?

```text
isdecimal() → most strict
isdigit()   → broader
isnumeric() → most flexible
```

## 16. What does replace() do?

It replaces occurrences of one substring with another.

## 17. What does encode() do?

It converts a string into bytes using an encoding.

## 18. What does decode() do?

It converts bytes back into a string.

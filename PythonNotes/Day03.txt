# 1. Comments in Python

## What are Comments?

A comment is a line of text in a Python program that is ignored by the Python interpreter.

Comments are used to:

- Explain the code
- Improve readability
- Add notes for developers
- Temporarily disable code during testing

---

# 2. Types of Comments

Python mainly uses two types of comments:

1. Single-line Comment
2. Multi-line Comment (using triple-quoted strings as documentation or multi-line text)

---

# 3. Single-Line Comment

A single-line comment starts with the hash (`#`) symbol.

## Syntax

```python
# This is a comment
```

## Example

```python
# Printing a welcome message
print("Welcome to Python")
```

### Output

```text
Welcome to Python
```

---

# 4. Multiple Single-Line Comments

```python
# Student Information
# Name : Rahul
# Course : Python
# Batch : PFS-101

print("Student Registered")
```

---

# 5. Multi-Line Comment

Python does not have a special multi-line comment syntax.

However, programmers often use triple-quoted strings (`'''...'''` or `"""..."""`) as documentation strings (docstrings) or for multi-line text.

## Using Triple Double Quotes

```python
"""
This program
demonstrates
multi-line text.
"""

print("Python")
```

## Using Triple Single Quotes

```python
'''
This is another
multi-line text block.
'''

print("Hello")
```

## Important Note

According to the Python documentation, triple-quoted strings are actually string literals.

When placed at the beginning of a module, function, or class, they become docstrings.

# 6. Swapping Two Variables

## Definition

Swapping means exchanging the values of two variables.

Suppose:

```python
a = 10
b = 20
```

After swapping:

```python
a = 20
b = 10
```

Three methods:

1. Using a Third Variable
2. Without Using a Third Variable (Arithmetic Method)
3. Pythonic Swapping (Recommended)

---

# 7. Method 1 — Using a Third Variable

## Algorithm

```python
temp = a
a = b
b = temp
```

## Example

```python
a = 10
b = 20

temp = a
a = b
b = temp

print(a, b)
```

### Output

```text
20 10
```

## Memory Representation

### Before

```text
a → 10
b → 20
```

### After

```text
a → 20
b → 10
```

---

# 8. Method 2 — Without Using a Third Variable

## Arithmetic Method

```python
a = a + b
b = a - b
a = a - b
```

## Example

```python
a = 10
b = 20

a = a + b
b = a - b
a = a - b

print(a, b)
```

### Output

```text
20 10
```

## Step-by-Step

| Step | Operation | a | b |
| --- | --- | ---: | ---: |
| Initial | — | 10 | 20 |
| 1 | `a = a + b` | 30 | 20 |
| 2 | `b = a - b` | 30 | 10 |
| 3 | `a = a - b` | 20 | 10 |

---

# 9. Method 3 — Pythonic Swapping

## Recommended Method

Python provides a simple way to swap variables without using a third variable.

## Syntax

```python
a, b = b, a
```

## Example

```python
a = 10
b = 20

a, b = b, a

print(a, b)
```

### Output

```text
20 10
```

This is the recommended and most commonly used method in Python.

---

# 10. Swapping Methods — Quick Comparison

| Method | Extra Variable | Main Idea | Recommendation |
| --- | --- | --- | --- |
| Third Variable | Yes | Use `temp` | Basic method |
| Arithmetic | No | Use `+` and `-` | Understand the logic |
| Pythonic | No | `a, b = b, a` | Recommended |

# 30. Single-Item Tuple

A single-item tuple is a common beginner mistake in Python.

## Incorrect Example

```python
student = ("Raju")

print(type(student))
```

### Output

```text
<class 'str'>
```

Python treats `("Raju")` as a string inside parentheses.

It is not a tuple.

---

# 31. Correct Single-Item Tuple

```python
student = ("Raju",)

print(student)
print(type(student))
```

### Output

```text
('Raju',)
<class 'tuple'>
```

The comma tells Python that this is a tuple.

---

# 33. Why Is the Comma Required?

Python identifies a tuple by the comma, not by the parentheses.

## Without Comma

```python
x = (5)

print(type(x))
```

### Output

```text
<class 'int'>
```

## With Comma

```python
x = (5,)

print(type(x))
```

### Output

```text
<class 'tuple'>
```

---

# 34. Interview Question — Single-Item Tuple

### Question

How do you create a tuple with only one element?

### Answer

A single-item tuple must end with a comma.

```python
student = ("Raju",)
```

Without the comma, Python treats it as a normal value enclosed in parentheses, not as a tuple.

# 43. Mutable vs Immutable

## Mutable Objects

Objects whose contents can change after creation.

Examples:

- list
- dictionary
- set
- bytearray

## Immutable Objects

Objects that cannot be changed after creation.

Examples:

- int
- float
- complex
- bool
- str
- tuple
- bytes
- frozenset
